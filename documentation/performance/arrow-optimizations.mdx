# Arrow/Parquet Optimizations

DeltaCAT leverages Apache Arrow's columnar format and zero-copy operations to provide high-performance data processing. The optimization system includes batch reading, predicate pushdown, and intelligent fragment management.

## Key Optimizations

<CardGroup cols={2}>
  <Card title="Batch Processing" icon="layer-group">
    Process data in configurable batches to optimize memory usage
  </Card>
  <Card title="Predicate Pushdown" icon="filter">

  <Card title="Fragment Coalescing" icon="object-group">

## Configuration

### Basic Setup

```python
from deltacat.config.performance import ArrowOptimizationConfig

config = ArrowOptimizationConfig(
    enabled=True,
    batch_size=65536,              # Rows per batch
    use_threads=True,               # Enable parallel processing
    num_threads=None,               # None = use all available cores
    enable_predicate_pushdown=True,
    enable_projection_pushdown=True
)
```

### Fragment Management

```python
config = ArrowOptimizationConfig(
    coalesce_small_files=True,
    min_fragment_size_mb=10,    # Files smaller than this are candidates
    target_fragment_size_mb=128  # Target size after coalescing
)
```

### Memory Management

```python
config = ArrowOptimizationConfig(
    memory_pool="jemalloc",  # or "system", None
    max_memory_mb=1024,      # Maximum memory for operations
    compression="snappy",     # Compression algorithm
    compression_level=None   # Algorithm-specific level
)
```

### Environment Variables

```bash
# Enable optimizations
export DELTACAT_ARROW_OPT_ENABLED=true

# Batch processing
export DELTACAT_ARROW_BATCH_SIZE=100000
export DELTACAT_ARROW_USE_THREADS=true

# Pushdown optimizations
export DELTACAT_ARROW_PREDICATE_PUSHDOWN=true

# Fragment coalescing
export DELTACAT_ARROW_COALESCE=true
```

## Usage Examples

### Optimized Scanning

```python
from deltacat.sql.arrow_adapter import create_optimized_scanner
import pyarrow.compute as pc

# Create an optimized scanner with predicate pushdown
scanner = create_optimized_scanner(
    dataset,
    columns=["id", "name", "amount"],  # Projection pushdown
    filter=pc.field("year") == 2024,    # Predicate pushdown
)

# Read data in batches
for batch in scanner.to_batches():
    process_batch(batch)
```

### Batch Reading

```python
from deltacat.sql.arrow_adapter import read_dataset_in_batches

# Read dataset in optimized batches
for batch in read_dataset_in_batches(
    dataset,
    batch_size=100000,
    columns=["id", "amount"],
    filter=pc.field("status") == "active"
):
    # Process each batch
    df = batch.to_pandas()
    results = process_dataframe(df)
```

### Fragment Coalescing

```python
from deltacat.sql.arrow_adapter import coalesce_small_fragments

# Optimize dataset with many small files
optimized_dataset = coalesce_small_fragments(
    dataset,

        min_fragment_size_mb=5,
        target_fragment_size_mb=100

# Query runs faster on optimized dataset
table = optimized_dataset.to_table()
```

## Advanced Features

### Parallel Processing

```python
from deltacat.sql.arrow_adapter import read_dataset_in_batches
from concurrent.futures import ThreadPoolExecutor

config = ArrowOptimizationConfig(
    use_threads=True,
    num_threads=8  # Use 8 threads for parallel reading
)

# Process batches in parallel
def process_batch(batch):
    return batch.column("amount").sum()

with ThreadPoolExecutor(max_workers=8) as executor:
    futures = []
    for batch in read_dataset_in_batches(dataset, config=config):
        future = executor.submit(process_batch, batch)
        futures.append(future)
    
    total = sum(f.result() for f in futures)
```

### Dataset Caching

```python
from deltacat.sql.arrow_adapter import get_dataset_cache

# Get the global dataset cache
cache = get_dataset_cache()

# Cache frequently used datasets
cache.put("popular_table", dataset)

# Retrieve cached dataset
cached_dataset = cache.get("popular_table")
if cached_dataset:
    # Use cached version
    result = cached_dataset.to_table()
```

### Metadata Caching

```python
from deltacat.sql.arrow_adapter import get_parquet_metadata

# Parquet metadata is automatically cached
```

## Optimization Strategies

### Small Files Problem

When dealing with many small Parquet files:

```python
config = ArrowOptimizationConfig(
    coalesce_small_files=True,
    min_fragment_size_mb=1,     # Very aggressive coalescing
    target_fragment_size_mb=256  # Larger target size
)

# Files will be logically grouped for better performance
optimized = coalesce_small_fragments(dataset, config)
```

### Large Dataset Queries

For queries on large datasets:

```python
# Use smaller batches to control memory
config = ArrowOptimizationConfig(
    batch_size=10000,        # Smaller batches
    max_memory_mb=512,       # Limit memory usage
    use_threads=True,        # Parallel processing
    num_threads=4            # Limit parallelism
)

# Stream results instead of loading all at once
for batch in read_dataset_in_batches(dataset, config=config):
    # Process incrementally
    partial_result = process(batch)
    save_partial(partial_result)
```

### Selective Reading

Minimize data transfer with pushdown:

```python
# Only read needed columns and rows
scanner = create_optimized_scanner(
    dataset,
    columns=["id", "total"],  # Only 2 columns instead of 50
    filter=(
        (pc.field("year") == 2024) &
        (pc.field("status").isin(["completed", "pending"]))
    )
)

# Dramatically reduces I/O and memory usage
result = scanner.to_table()
```

## Performance Tuning

### Batch Size Selection

Choose batch size based on your workload:

```python
# Interactive queries - smaller batches for responsiveness
config.batch_size = 10000

# Batch processing - larger batches for throughput
config.batch_size = 100000

# Memory-constrained - calculate based on available memory
import psutil
available_mb = psutil.virtual_memory().available / 1024 / 1024
rows_per_mb = 1000  # Estimate based on your data
config.batch_size = int(available_mb * rows_per_mb / 10)  # Use 10% of available
```

### Thread Pool Tuning

```python
import os

# CPU-bound operations
config.num_threads = os.cpu_count()

# I/O-bound operations
config.num_threads = os.cpu_count() * 2

# Mixed workloads
config.num_threads = int(os.cpu_count() * 1.5)
```

### Compression Selection

```python
# Fast compression for temporary data
config.compression = "lz4"
config.compression_level = 1

# Balanced compression
config.compression = "snappy"

# Maximum compression for archival
config.compression = "zstd"
config.compression_level = 9
```

## Performance Impact

Arrow optimizations provide substantial improvements:

- **Query Speed**: 40-70% faster for large datasets
- **Memory Usage**: 50-80% reduction with batching
- **I/O Reduction**: 60-90% with predicate pushdown
- **Small Files**: 3-10x faster with coalescing

The benefits are most significant for:
- Large analytical queries
- Datasets with many small files
- Selective queries (few columns/rows needed)
- Memory-constrained environments
