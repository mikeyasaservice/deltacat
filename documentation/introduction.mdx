# DeltaCAT

DeltaCAT is a portable Pythonic Data Lakehouse powered by [Ray](https://github.com/ray-project/ray). It provides a unified interface for managing exabyte-scale data lakes with ACID compliance and multimodal support.

## What is DeltaCAT?

DeltaCAT combines the best of data lakes and data warehouses into a unified platform that scales from gigabytes to exabytes. It has been successfully deployed in production to [manage exabyte-scale enterprise data lakes at Amazon](https://aws.amazon.com/blogs/opensource/amazons-exabyte-scale-migration-from-apache-spark-to-ray-on-amazon-ec2/).

## Key Features

### Unified Compute Engine
DeltaCAT automatically routes queries to the optimal compute engine based on data size and query complexity:
- **DuckDB** for analytical queries on small to medium datasets (<100GB)
- **Daft** for large-scale distributed processing
- **Ray** for ML workloads and Python UDF execution

### Multi-Format Support
Work seamlessly across different table formats:
- **Apache Iceberg** with full read/write support and time travel
- **Delta Lake** integration (coming soon)
- **Parquet** for high-performance columnar storage

### Enterprise Ready
- **Unity Catalog Integration** for centralized governance
- **Schema Evolution** without data rewriting
- **Partition Pruning** for automatic query optimization
- **ACID Transactions** for data consistency

- Leverage Ray's distributed computing for parallel processing
- Automatic query optimization with partition pruning

### Developer Friendly
