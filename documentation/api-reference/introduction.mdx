## Quick Reference

### Initialization

```python
import deltacat

# Basic initialization
deltacat.init()

# With custom configuration
deltacat.init(
    catalog_properties={
        "catalog_type": "unity",
        "warehouse_path": "s3://bucket/warehouse"
    }
)
```

### Catalog Operations

```python
from deltacat import catalog

# Namespace operations
catalog.create_namespace("my_db")
catalog.list_namespaces()

# Table operations
catalog.create_table("my_db", "my_table", schema)
catalog.read_table("my_db", "my_table")
catalog.write_to_table("my_db", "my_table", data)
```

### Compute Operations

```python
from deltacat.compute.engine import create_engine

# Create unified engine
engine = create_engine()

# Execute queries
result = engine.execute("SELECT * FROM table")

# Specify engine explicitly
result = engine.execute(
    "SELECT * FROM large_table",
    engine="daft"
)
```

### Storage Operations

```python
from deltacat.storage.formats import UnifiedTableInterface

# Create table interface
table = UnifiedTableInterface("s3://bucket/table")

# Read/write operations
df = table.read(columns=["id", "name"])
table.write(df, mode="append")

# Get metadata
metadata = table.get_metadata()
```

## Common Patterns

### Error Handling

```python
from deltacat.exceptions import TableNotFoundError, CatalogError

try:
    table = catalog.get_table("db", "table")
except TableNotFoundError:
    print("Table not found")
except CatalogError as e:
    print(f"Catalog error: {e}")
```

### Context Managers

```python
from deltacat import catalog

# Automatic resource cleanup
with catalog.session() as session:
    session.create_table("db", "table", schema)
    session.write_data(data)
    # Commits on exit, rolls back on error
```

### Async Operations

```python
import asyncio
from deltacat.async_api import AsyncCatalog

async def main():
    catalog = AsyncCatalog()
    
    # Concurrent operations
    tasks = [
        catalog.read_table("db", "table1"),
        catalog.read_table("db", "table2"),
        catalog.read_table("db", "table3")
    ]
    
    results = await asyncio.gather(*tasks)
```

## Configuration

### Environment Variables

```python
import os

# Catalog configuration
os.environ["DELTACAT_CATALOG_TYPE"] = "unity"
os.environ["DELTACAT_WAREHOUSE_PATH"] = "s3://bucket/warehouse"

# Compute configuration
os.environ["DELTACAT_DEFAULT_ENGINE"] = "daft"
os.environ["DELTACAT_ENGINE_MEMORY_LIMIT"] = "32GB"

# Storage configuration
os.environ["DELTACAT_DEFAULT_FORMAT"] = "iceberg"
os.environ["DELTACAT_COMPRESSION"] = "snappy"
```

### Programmatic Configuration

```python
from deltacat.config import Config

config = Config(
    catalog_type="unity",
    default_engine="daft",
    storage_options={
        "default_format": "iceberg",
        "compression": "snappy"
    }
)

deltacat.init(config=config)
```

## Performance Tips

1. **Use column selection** to reduce data transfer:
   ```python
   df = table.read(columns=["id", "name"])
   ```

2. **Enable partition pruning** for large tables:
   ```python
   df = table.read(filter="date >= '2024-01-01'")
   ```

3. **Batch operations** for better throughput:
   ```python
   with catalog.batch_writer("db", "table") as writer:
       for batch in data_batches:
           writer.write(batch)
   ```
